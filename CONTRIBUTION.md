# Improving the material

You can propose any edits to the material:

- Fixing typos
- Pointing to interesting sources that could enrich the content
- Additional clarifications of the existing material
- New vivid examples and explanations
- New problems or solutions to existing ones
- Even new articles!

If your suggestions lead to adding new content **(other than typo reports!)**, we can add your info (name, photo, a few words about you, and links) to the authors page if you want it.

You can propose changes in two ways:

1. Edit the material directly on GitHub and open a Pull Request.
2. Contact me via Telegram ([@gwynerva](https://t.me/gwynerva)) or email ([newpetya@inbox.ru](mailto:newpetya@inbox.ru)).
3. Install a local copy of project on your PC to make large contributions.

# Rules for using links

Do not add a link to a unique element if it is in the same section (under the same H1, H2, H3 heading).

If a unique element is in another section, link to it in the new section no more than once in each "scope." For example, you can link once in the paragraphs of that section and once in initially hidden blocks, such as hints and solutions to problems.

For problems, if the link is not directly in the statement, duplicate it as needed once in each section where it is required (hints, solution, answer, note).
